# AGENTS.md 调用与阶段提醒

初始化完成后或用户要求时，提出以下指引块。只更新仓库根目录的 AGENTS.md，保留块外内容；用标记就地更新，不重复插入。写入需要用户授权；已经批准下面文字时直接执行，不重复索要批准。若安装环境不能按名称发现 skill，明确记录其可访问位置，不编造路径。

## 指引块

    <!-- DS_git-versioning:begin -->
    用户明确要求保存、查看、比较、撤销、重做或恢复项目版本时，委托一个 sub-agent 使用 `DS_git-versioning`，提供操作意图、仓库及文件范围、本阶段修改与必要原因、目标版本（如需）和已知需保留的其他工作，期间暂停相关编辑及其他 Git 写操作。
    每完成一个阶段的任务，并且有文件改动、且尚未保存为版本的，询问一次：“本阶段已完成，要保存一个版本吗？”用户同意后再执行；查看、讨论和刚完成存档时不重复询问
    <!-- DS_git-versioning:end -->

模板保持两条规则，项目使用其他语言时等义翻译。交接和阶段提醒必须写入主 Agent 实际读取的 AGENTS.md，不能依赖主 Agent 先加载本技能；子代理的核对及执行细节留在 SKILL.md 和对应下钻文档中。

## 完成检查

指引块恰好一份，文字已获授权，块外内容保留。实际 AGENTS.md 写入是否提交由本次授权范围决定，不顺带混入其他阶段的提交。
