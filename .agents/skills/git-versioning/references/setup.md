# 初始化与追踪范围

## 确认仓库

确认用户指定的项目根目录，用 Git 检查是否位于已有仓库内；不创建嵌套仓库，也不重新初始化现有仓库。

已有仓库默认沿用当前分支与配置，普通存档直接转到 [commit.md](commit.md)，不顺带补写 `.gitignore`、`.gitattributes` 或 AGENTS.md。只有用户明确要求维护版本管理配置时，才按获授权范围修改，需要提交时单独提交；检查发现配置缺项时可报告，不自动补齐。遇到冲突、未完成操作或分离 HEAD 时阅读 [conflicts.md](conflicts.md)。

## 新建仓库

1. 用户同意后运行 `git init -b main`。
2. 首次提交前检查现有身份；缺少姓名或邮箱时，通过主 Agent 询问用户并仅设置本仓库配置。不猜测身份。说明这些信息会写入提交，日后分享仓库时也会被带上。
3. 添加下述忽略与属性规则。基线仅包含获授权的项目文档及必要管理文件，按 [commit.md](commit.md) 提交。若本阶段已经包含待保存的修改，不再为同一状态重复创建空的阶段提交。
4. 通过 [agents-md.md](agents-md.md) 提供 AGENTS.md 指引，并将下述媒体命名与归档约定返回主 Agent；指引的写入授权与版本保存授权分别判断，不擅自扩大提交范围。

## 文档与媒体

- 文本、Markdown，以及 Word、Excel、PPT、PDF 等文档型二进制内容可以纳入 Git。文档导出文件只要属于用户的项目交付物，也可以保存快照。
- 二进制文档按整份文件保存和恢复，不承诺 Git 内容比较或自动合并。不为它们增加 LFS、插件或合并驱动。
- 图片和视频无论是原稿、导出文件还是旧版归档，都不纳入 Git；SVG 等文本形式的图片除外。
- 追踪判断以文件用途为准，不能把后缀列表当成完整分类器。明显的大型附件在首次提交前先说明大小及影响。

初始化时根据项目实际媒体类型生成 `.gitignore` 规则，将图片、视频及其归档排除出追踪，覆盖大小写变体，并用 `git check-ignore` 核验。不笼统忽略所有名为 `archive/` 的目录，以免漏掉应保存的归档文档。

已被跟踪的媒体不会因为加入忽略规则就停止追踪。接管时列出这类文件，通过主 Agent 确认后用明确路径执行 `git rm --cached -- <paths>`，保留本地文件并将停止追踪记录为一次维护提交。不自动清理旧提交里的媒体；说明旧媒体仍占用历史空间。此配置迁移与用户的阶段提交分开，不混入本阶段文档改动。

常用噪声可以忽略：`.DS_Store`、`Thumbs.db`、`desktop.ini`、`~$*`、`.~lock.*#`、`*.tmp`、`*.crdownload`。为防误提交添加 `.env`、`.env.*`、`.env/` 等忽略规则，但不读取其内容。

新仓库通过 `.gitattributes` 的 `* -text` 禁用自动换行转换，按原始字节保存文件的 LF 或 CRLF，避免恢复或冲突中止时隐式改变换行。这不关闭文本差异查看；文档型二进制另按下方规则标记。已有仓库保留其换行约定，不为此次存档或恢复改配置或执行批量换行转换。

`.gitattributes` 示例，按项目实际文档格式补充：

    * -text
    *.docx binary
    *.xlsx binary
    *.pptx binary
    *.pdf binary
    *.doc binary
    *.xls binary
    *.ppt binary
    *.odt binary
    *.ods binary
    *.odp binary

## 图片和视频的文件名归档

由主 Agent 在生成或更新媒体的内容任务中执行，Git 子代理不在提交时顺带批量重命名或移动媒体。

- 名称采用 `主题_版本简述.后缀名`，例如 `方案_蓝色封面.png`。
- 同一素材的新版本验证可用后，将旧版移入原目录下的 `archive/`；原目录只保留该素材的新版，不影响其他素材。
- 保留旧版文件名，不覆盖归档中的同名文件；重名时补充简短区别或日期。
- 移动前确认新旧版本对应关系及目录用途；同步更新本阶段文档中的相关引用，避免图片链接失效。
- 不因更新 Git 规范而自动整理用户已有媒体。媒体文件名和归档由文件系统管理，Git 的恢复不会恢复这些媒体或撤销其移动。

## 完成检查

确认仓库根目录、获授权文件及提交结果。用 `git check-ignore` 和 `git ls-files` 核对媒体规则及已追踪媒体状态；保留其他改动。没有远程就跳过远程说明；若已有远程，仅说明本次保存仍是本地版本，不修改或同步远程。
